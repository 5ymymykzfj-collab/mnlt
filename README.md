# Тестовое задание

Консольное приложение на JavaScript для формирования заявки на продукты питания с учетом региона, группы товара и логики удержания клиента.

## Требования

- Node.js 18 или выше

## Запуск

```bash
npm start
```

или:

```bash
node app.js
```

## Что умеет приложение

- предлагает выбрать регион: СПБ, МСК или КРД;
- показывает локальный каталог продуктов с региональными ценами;
- принимает выбор товара и корректно повторяет ввод при ошибках;
- показывает заказ перед оформлением;
- при подтверждении создает JSON-файл заявки в папке `requests`;
- при отказе определяет группу товара и предлагает:
  - самый дешевый аналог из той же группы;
  - скидку 5%, если выбранный товар уже самый дешевый в группе.

## Данные

В каталоге 12 товаров и 6 категорий:

- Молочные продукты
- Хлеб и выпечка
- Фрукты
- Мясо и птица
- Бакалея
- Напитки

## Формат заявки

После подтверждения заявка сохраняется в файл вида:

```text
requests/request-1780000000000.json
```

Файл содержит дату создания, регион, выбранный товар, цену и, если применимо, финальное предложение для удержания клиента.
